Description

This course takes you from an empty folder to a published, responsive website.

You won't install a framework or copy code you don't understand. Instead you'll learn the three languages every web page is made of, in the order that makes them easiest to learn:

  1. HTML for structure and meaning
  2. CSS for layout and style
  3. JavaScript for behaviour

Each section ends with a small project. By the end you'll have three finished pages and the vocabulary to keep learning on your own.
